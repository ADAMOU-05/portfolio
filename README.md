# Mon portfolio

Ce site présente mon parcours, mes compétences et mes projets.

## Les pages

- `index.html` : mon portfolio personnel.
- `projet-ecoute-coran/index.html` : le site An•noor pour chercher et écouter des sourates.
- `projet-citations-informatique/index.html` : une page de citations et de bandes dessinées sur l’informatique.
- Les autres pages du dossier An•noor présentent mon profil, une biographie, des vidéos et un verset.

## Fonctions d’An•noor

- Chercher une sourate par son nom.
- Lancer une sourate et passer à la suivante ou à la précédente.
- Mettre l’audio en pause, régler le volume et suivre sa progression.

Les fonctions principales sont dans `projet-ecoute-coran/jav.js`. La liste des sourates est dans `projet-ecoute-coran/list-sourates.js`.

## Ouvrir le site

Ouvrez le fichier `index.html` dans un navigateur. Pour découvrir An•noor, cliquez sur le lien du projet dans mon portfolio.
